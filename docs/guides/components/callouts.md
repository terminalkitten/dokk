title: Callouts
description: Notes, tips, cautions and warnings that stand out from the text.
sidebar:

---

Four types: `note`, `tip`, `caution` and `danger`. A `[title]` replaces the default one.

```md
:::note
The default title is the type.
:::

:::tip[Custom title]
Callouts hold any **Markdown**.
:::
```
